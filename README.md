# Tailwind CSS — 30 Days Mastery Journey

A complete 30-day hands-on learning journey focused on mastering Tailwind CSS from beginner to advanced level through daily practice, UI recreations, responsive layouts, and real-world frontend projects.

---

# Goal

The goal of this repository is to:

- Learn Tailwind CSS step-by-step
- Build modern responsive interfaces
- Master utility-first CSS workflow
- Develop real-world frontend skills
- Become job-ready in frontend UI development

# Git Workflow

Each learning day uses its own branch.

## Example Workflow

Create new branch:

```bash
git checkout -b day-01
```

Push branch:

```bash
git push -u origin day-01
```

Merge into main:

```bash
git checkout main
git merge day-01
git push origin main
```
